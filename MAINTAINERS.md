# Maintainers

Active maintainers of Flutter Intents:

| Name | GitHub | Areas |
| ---- | ------ | ----- |
| touyou | [@touyou](https://github.com/touyou) | All packages, releases, design |

If you would like to help maintain the project, please reach out via the
maintainer's [GitHub profile](https://github.com/touyou) or open a feature
request issue.

## Responsibilities

- Reviewing and merging pull requests.
- Triaging issues filed via the [`bug_report`](.github/ISSUE_TEMPLATE/bug_report.yml) and
  [`feature_request`](.github/ISSUE_TEMPLATE/feature_request.yml) templates.
- Coordinating releases per [RELEASING.md](RELEASING.md).
- Responding to security reports under [SECURITY.md](SECURITY.md).
- Upholding the [Code of Conduct](CODE_OF_CONDUCT.md).
