# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1][covenant] as its code of conduct.
By participating in this project — through issues, pull requests, discussions, or any other
channel — you agree to abide by its terms.

The full text is available at:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## Reporting

If you experience or witness behavior that violates the Contributor Covenant, please report it
**privately** so the maintainers can follow up:

- Open a confidential report via GitHub Security Advisories:
  https://github.com/touyou/flutter_intents/security/advisories/new
  (Security Advisories are private; use the description field to summarize the incident.)
- Or contact the maintainer directly via their GitHub profile:
  https://github.com/touyou

All reports will be reviewed and investigated promptly and fairly. Maintainers are obligated
to respect the privacy and safety of the reporter.

## Enforcement

Maintainers will follow the [Contributor Covenant's Enforcement Guidelines][guidelines] when
deciding on consequences for any behavior they deem in violation of this Code of Conduct.

[covenant]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
[guidelines]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines
